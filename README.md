# STM32 恐龙跑酷游戏

一个基于 STM32F103C8T6 和 0.96寸 OLED 屏幕的嵌入式小游戏，复刻了经典的 Chrome 浏览器断网小恐龙玩法。

## 📖 项目简介
本项目实现了恐龙自动跑动、随机生成障碍物（仙人掌）、按键跳跃避障以及分数统计（可选）的功能。使用 C 语言编写，基于 STM32 标准库开发。

## ⚙️ 硬件环境
*   **主控芯片**：STM32F103C8T6 (Blue Pill)
*   **显示屏**：0.96寸 OLED (SSD1306 驱动, 分辨率 128x64, I2C 接口)
*   **输入设备**：按键（支持 EXTI 外部中断触发）
*   **开发工具**：Keil uVision 5

## 🚀 快速开始
1.  克隆或下载本工程代码。
2.  使用 Keil uVision 5 打开工程文件。
3.  确保已安装 STM32F10x 固件库。
4.  点击 `Rebuild` 编译工程。
5.  连接 ST-Link，下载 `.hex` 文件到开发板。
6.  按下 **PA1 按键** 即可开始游戏。

## 🎮 核心功能与实现

### 1. 跳跃物理引擎
采用离散抛物线公式计算恐龙跳跃高度：
height = phase * (JUMP_TOTAL - phase) * 4 * PEAK / (JUMP_TOTAL * JUMP_TOTAL);

*   `JUMP_TOTAL`：控制跳跃总时长（滞空时间）。
*   `PEAK`：控制跳跃最大高度。
*   通过调节这两个宏定义，可以改变手感和躲避宽障碍物（如 24px 仙人掌）的能力。

### 2. 随机障碍生成
使用 **SysTick 计时器** 的当前值 (`SysTick->VAL`) 作为随机种子 (`srand`)。
*   **优势**：相比固定的种子，SysTick 在按下按键瞬间的值具有极高的随机性，确保每次开局地形都不一样。
*   **数据结构**：使用长度为 5 的环形队列 (`cactus_array`) 管理屏幕上的仙人掌，节省内存并高效处理进出屏幕的逻辑。

### 3. 图形渲染
*   使用 **帧缓冲 (FrameBuffer[8][128])**：在内存中先画好一整帧画面，然后通过 DMA 或快速 I/O 一次性刷新到 OLED，解决屏幕闪烁问题。
*   **位运算绘图**：恐龙跳跃时，针对像素进行位偏移（`<<`, `|`, `>>`），实现非 8 倍数高度的平滑显示。

## 🐛 常见问题
*   **Q: 按键没反应？**
    *   A: 检查 `EXTI1_IRQHandler` 是否配置正确，检查 `stm32f10x_it.c` 中是否开启了 `JumpFlag`。
*   **Q: 跳不过宽的仙人掌？**
    *   A: 检查 `Items.c` 中的 `JUMP_TOTAL` 是否修改得足够大（建议 60+），且中断函数里的 `JumpNum` 赋值是否同步修改。
*   **Q: 编译报错 Multiple Definition？**
    *   A: 检查 `OLED_Font.h` 中是否包含了 `extern` 声明，而实际的数组定义放在了 `.c` 文件中。
